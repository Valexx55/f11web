GIT

SISTEMA DE CONTROL DE VERSIONES
PARA COMPARTIR CÓDIGO

TENGO QUE TENER INSTALADO GIT EN MI ORDENADOR
https://gitforwindows.org/

PARA COMPROBAR SI TENGO GIT INSTALADO, EN LÍNEA DE COMANDOS EJECUTO
git --version
o 
git -v 


PARA COPIAR POR PRIMERA VEZ EN UN PC, EL REPO DE CLASE, HACEMOS

git clone https://github.com/Valexx55/f11web

DEPUÉS, HAGO change directory cd

cd f11web 

PARA SITUARME EN EL DIRECTORIO RAÍZ DEL REPOSITORIO

DESDE ESE DIRECTORIO , PARA ACTUALIZARME HAGO

git pull

SIEMPRE HARÉ git pull desde f11web PARA ACTUALIZAR LO DEL PROFE

SI EJECUTO 

git remote -v

origin  https://github.com/Valexx55/f11web.git (fetch)
origin  https://github.com/Valexx55/f11web.git (push)

PUEDO VER CON QUÉ REPOSITORIO REMOTO ESTÁ CONECTADO MI REPOSITORIO LOCAL

LA CARPETA FF11WEB DE PROFE ES DE SÓLO LECTURA
SI ESCRIBO ALGO POR ERROR Y LUEGO HAGO git pull, SEGURAMENTE
QUE DE FALLO, PORQUE LA VERSIÓN REMOTA (PROFE) Y LA LOCAL NO COINCIDEN
PARA SOLUCIONAR EL CONFLITO USAMOS

git reset --hard origin/master

ESTO, SOBREESCRIBE TODOS LOS CAMBIOS LOCALES POR LOS REMOTOS
