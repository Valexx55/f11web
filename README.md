# Recursos para aprender HTML y CSS


## HTML

### W3Schools - HTML

Tutoriales básicos y ejemplos prácticos para aprender HTML desde cero.

[https://www.w3schools.com/html/default.asp](https://www.w3schools.com/html/default.asp)

### MDN Web Docs - HTML

Documentación oficial y muy completa sobre HTML. Muy recomendable para consultar etiquetas, atributos y buenas prácticas.

[https://developer.mozilla.org/es/docs/Web/HTML#tutoriales_para_principiantes](https://developer.mozilla.org/es/docs/Web/HTML#tutoriales_para_principiantes)

## Herramientas para diseño web

### Favicon.io

Herramienta para generar favicons para una página web.

[https://favicon.io/](https://favicon.io/)

### HTML Color Codes

Página para consultar códigos de colores en HTML y CSS, incluyendo valores HEX, RGB y HSL.

[https://htmlcolorcodes.com/](https://htmlcolorcodes.com/)

### Bootstrap Icons

Biblioteca de iconos gratuitos que pueden usarse en proyectos web.

[https://icons.getbootstrap.com/](https://icons.getbootstrap.com/)

## Juegos para practicar CSS

### CSS Diner

Juego para practicar selectores CSS de forma visual e interactiva.

[https://flukeout.github.io/](https://flukeout.github.io/)

### Flexbox Froggy

Juego para aprender y practicar Flexbox de forma sencilla.

[https://flexboxfroggy.com/#es](https://flexboxfroggy.com/#es)

## Diagramas y planificación

### diagrams.net

Herramienta gratuita para crear diagramas, esquemas, mapas de navegación, diagramas de flujo y otros modelos visuales.

[https://app.diagrams.net/](https://app.diagrams.net/)

## Validación de código

### W3C Markup Validation Service

Validador oficial para comprobar si el código HTML está bien escrito y sigue los estándares web.

[https://validator.w3.org/#validate_by_input](https://validator.w3.org/#validate_by_input)
